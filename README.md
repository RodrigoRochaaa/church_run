# church_run

Mod multiplayer para Project Zomboid **Build 42 (42.20+)**: o grupo conquista, uma a uma, a igreja principal de cada cidade de Knox Country, sobrevivendo a ondas de zumbis com tempo marcado.

**Status:** em desenvolvimento, Fase 0 (fundação). Ainda não há versão jogável nem página no Workshop.
